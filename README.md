# Snake Eat Apples

A Snake game built with Python and pygame-ce. Eat apples, grow longer, and beat your best score.

## Features
- Grass background
- Apples to eat
- Score and best score
- Game speeds up as you score

## How to run
1. Install Python
2. Install pygame-ce: `pip install pygame-ce`
3. Run the game: `python snake_apple.py`

## Controls
- Arrow keys or W/A/S/D: move
- R: restart after game over
